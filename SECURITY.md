# Security Policy

## Supported versions

Only the latest release of Solid Self receives fixes.

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| < 1.1 | No |

## Reporting a vulnerability

Solid Self runs only on your own game client and does not use the network. If you still find a security problem, please **do not open a public issue**. Report it privately instead:

- through [GitHub's private vulnerability reporting](https://github.com/Cloakyi/solid-self/security/advisories/new), or
- by email to [support@cloaki.de](mailto:support@cloaki.de)

You will get an answer as soon as possible.

## Downloads

Only download Solid Self from [Modrinth](https://modrinth.com/mod/solid-self) or the [GitHub releases](https://github.com/Cloakyi/solid-self/releases). Copies from other sites may be modified.
